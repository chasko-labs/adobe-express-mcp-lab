# spec — firefly tic-tac-toe (bryanchasko.com/firefly-tic-tac-toe)

> **Status:** draft · **Type:** new product (sibling, not mode) · **Route:** `bryanchasko.com/firefly-tic-tac-toe`
> **Template:** `spec/use-cases/aws-builder-center-banner-spec.md` atomized pattern
> **MCP:** `@adobe/express-developer-mcp@1.0.0` · `manifestVersion: 2` · `express-document-sdk` · iframe ↔ documentSandbox via Communication APIs
> **Sibling ref:** `/sumerian-squares` (content/layouts/assets pattern) · sibling prefixes `/design`, `/listen`, `/mom`, `/bench`, `/chat`, `/news`, `/aws` (see `s3-prefix-registry.json` + `buildspecs/buildspec-deploy.yml` excludes)

## objective

Ship **Firefly Tic-Tac-Toe** as a standalone product at `bryanchasko.com/firefly-tic-tac-toe` — 3×3 tic-tac-toe reskinned with 9 Firefly-generated hosts — plus an **Adobe Express Add-on generator** (manifest V2 panel) that lets users generate a branded board/banner in Express via Firefly fetch in iframe → proxy to documentSandbox → `editor.createRectangle` + `makeImageFill` append. Hugo page is 2D/canvas only (esbuild), 3×3 engine reused verbatim from `sumerian-squares`. Not a mode or flag of `sumerian-squares`.

## non-goals

- No change to `content/sumerian-squares/`, `assets/sumerian-squares/`, `layouts/page/sumerian-squares.html`.
- No Babylon/WebGL/3D — Firefly Tic-Tac-Toe is 2D canvas/DOM + esbuild.
- No backend — Firefly calls from iframe (full `fetch`) proxied to sandbox; no server.
- No new sibling S3 prefix — Hugo-managed `/firefly-tic-tac-toe/` syncs to `s3://bryanchasko.com/firefly-tic-tac-toe/` under root bucket (like `sumerian-squares`).
