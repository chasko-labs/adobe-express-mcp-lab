## what this is

ASL avatar integration for **Firefly Tic-Tac-Toe** — sign-accurate, art-directable avatars (Sumerian clay → Firefly generative → Universal) that sign the gloss sequence powering the 3×3 board's trivia/announcer layer. The pipeline is:

```
Gloss (G01–G72 HELLO/WORLD/… 420ms) → Firefly Vary / Custom Model (styleReference + structureReference, seed 4219) → Babylon.js rig (42 joints 74–115 HOST_SCORECARD) → Express panel (asl-concept / asl-lab makeImageFill) → Hugo demo/guide (2D preview)
```

- **Hugo pages** (`asl-demo`, `asl-guide`) are 2D/DOM only — no Babylon bundle — they preview/document the pipeline.
- **Add-ons** (`addons/asl-concept` mock from prior result 1, `addons/asl-lab` lab from prior results 6–7) are where the 3D + Firefly Twin run (iframe `fetch` → sandbox `editor.createRectangle`/`makeImageFill`).
- **Living guide** `docs/asl-concept-guide/README.md` is the single ever-improving source for `babylonjs` SceneLoader + Firefly fetch + gloss JSON snippets; Hugo `asl-guide` mirrors it.
